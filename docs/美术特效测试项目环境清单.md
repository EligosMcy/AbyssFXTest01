## 5. 分层与排序层

**Layer（自定义部分）**：`FxTemporaire`、`DropArea`、`HandCard`、`Overlay`、`Enemy`、`Player`、`Foreground`、`BackgroundUI`、`unknown_20003`

**Sorting Layer（从后到前）**：
`Default` → `Background` → `Combatan View` → `Forward` → `Unit UI` → `Unit UI Feedback` → `Card View` → `TargetArrowView` → `UI` → `Presentation Background` → `Presentation Combatant` → `Presentation Foreground` → `UI Card View` → `Presentation` → `Presentation Feedback`

> 特效请优先使用 `Presentation` / `Presentation Feedback` / `Card View` 等与游戏一致的层，避免回迁时排序错乱。
